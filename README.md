## Featured projects

### [Skill Hub for Command Code](https://github.com/PabloJustDevelops/skill-hub-mod)

A TypeScript mod that keeps Command Code skills up to date and provides stack-aware recommendations using local project signals.

- Slash commands such as `/skillhub list`, `/skillhub check`, `/skillhub update`, and `/skillhub recommend`
- Local stack detection from files such as `package.json`, `tsconfig.json`, `requirements.txt`, and `Dockerfile`
- Confirmation-first updates with no surprise installations
- MIT licensed and ready to use as a Command Code mod or a standalone skill

### [Automata Core](https://github.com/PabloJustDevelops/Automata-Core-App)

A Python multimodal desktop assistant combining conversational AI, computer vision, OCR, voice, gesture recognition, QR decoding, and document analysis in a Flet interface.

- LLM integrations with Groq and Google Gemini
- OpenCV camera processing, Tesseract OCR, MediaPipe gestures, and QR scanning
- Voice input/output with SpeechRecognition, PyAudio, and pyttsx3
- Support for PDF, DOCX, TXT, and image-based workflows

### [Brandio Car Brand Detection](https://github.com/PabloJustDevelops/Brandio-Car-Detection)

A real-time vehicle-brand detection platform built around YOLOv4 and OpenCV, with a decoupled web application and administration services.

- Flask detection application with webcam/video processing
- YOLOv4 model inference and OpenCV image pipelines
- MQTT communication between detection, broker, and logging services
- SQLite event history with a Streamlit analytics dashboard
- CSV and PDF reporting with pandas, Plotly, ReportLab, and OpenPyXL

### [Hyprland Dotfiles](https://github.com/PabloJustDevelops/dotfiles)

Personal Hyprland configuration for CachyOS/Arch Linux, designed around a minimal development and gaming workflow on NVIDIA hardware.

- Hyprland, Waybar, Rofi, Dunst, and Kitty
- Wayland/NVIDIA environment configuration and keyboard-driven workflows
- Catppuccin-inspired styling and lightweight shell utilities
- GPU/performance helpers for Steam, MangoHud, GameMode, and `nvidia-smi`
